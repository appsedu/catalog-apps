## Contributing

Found a mistake, a broken link, or know an open-source app compatible with Debian/Ubuntu that is missing from the list?

1. Open an [issue](https://github.com/appsedu/awesome-educational-apps-for-linux/issues)
2. Or send a pull request updating [`apps.json`](apps.json)

We prefer **open-source** apps with clear installation steps and real educational value.

Each entry in `apps.json` follows this format:

```json
{
  "app": "Stellarium",
  "text": "Gerador de céu fotorrealístico em tempo real",
  "page": "https://stellarium.org",
  "install": "sudo apt install stellarium",
  "img": "https://screenshots.debian.net/screenshot/stellarium",
  "categories": ["Astronomia"]
}
```

> **Note:** Some packages require the [WinuniX repository](https://winunix.github.io/debian/) configured on the system.
