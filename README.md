## Contribuindo

Encontrou um erro, um link quebrado ou conhece um app open source compatível com Debian/Ubuntu que falta na lista?

1. Abra uma [issue](https://github.com/appsedu/awesome-educational-apps-for-linux/issues)
2. Ou envie um pull request atualizando [`apps.json`](apps.json)

Preferimos apps **open source**, com instalação clara e utilidade real em contexto educativo.

Cada entrada em `apps.json` segue este formato:

```json
{
  "app": "Stellarium",
  "text": "Gerador de céu fotorrealístico em tempo real",
  "page": "https://stellarium.org",
  "install": "sudo apt install stellarium",
  "img": "https://screenshots.debian.net/screenshot/stellarium",
  "categories": ["Astronomia"]
}
```

> **Nota:** Alguns pacotes exigem o [repositório WinuniX](https://winunix.github.io/debian/) configurado no sistema.
